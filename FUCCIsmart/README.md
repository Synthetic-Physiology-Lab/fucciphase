# FUCCIsmart package

This folder contains a representative implementation of the FUCIsmart event-driven imaging framework for Nikon microscopes, enabling cell-cycle-aware adaptive acquisition based on FUCCI reporters.

## File description
* `FuccilPlex_SmartMicroscopy_automatic.bin` : JOBS routine for automated FUCCIsmart implementation
* `FuccilPlex_SmartMicroscopy.bin`: JOBS routine for FUCCIsmart implementation on selected cell population
* `FUCCISmart_MainLoopTimeLapseCel1X-27992.100Y22679.600` : Representative raw data for main loop cell
* `FUCCISmart_MainLoop000_ClassG2_G2Loop_G2ce11X-27992.100Y22679.600` : Representative raw data for G2
loop selected cell
* `FUCCISmart_MainLoop000_ClassG2_Loop-004_Mce11-X-27992.100Y22679.600` : Representative raw data for M loop selected cell
